# 📊 E-Commerce Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Power BI Dashboard** developed to analyze e-commerce sales performance and provide meaningful business insights through data visualization. The dashboard enables businesses to monitor revenue, orders, customer behavior, product performance, and sales trends, helping stakeholders make data-driven decisions.

> **Dataset Source:** The dataset used in this project was downloaded from **Kaggle**.

---

# 🎯 Business Problem

E-commerce businesses generate large volumes of transactional data every day. Without proper visualization, it becomes difficult to:

- Monitor overall sales performance.
- Track revenue and order trends.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Make informed business decisions.

This dashboard transforms raw sales data into interactive visual reports that support strategic decision-making.

---

# 🎯 Objectives

- Analyze overall business performance.
- Track total revenue and total orders.
- Monitor customer purchasing trends.
- Identify top-performing products.
